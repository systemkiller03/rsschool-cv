Code Example

A kata I solved on Codewars: finding the digital root of a number. 

function digitalRoot(n) {
  while (n >= 10) {
    n = String(n)
      .split('')
      .reduce((sum, digit) => sum + Number(digit), 0);
  }
  return n;
}
